ESP32 SD Card NAS Web Server

Turn your ESP32 + SD card into a highly secure, offline Network Attached Storage (NAS) device. Featuring Role-Based Access Control, brute-force IP protection, live server logs, and advanced system monitoring.

Explore Features

Core NAS Capabilities

Standalone AP Mode

Creates a secure, offline Wi-Fi network (wireless server). No external router needed to access files.

Advanced Security

Session-based authentication, path traversal blocking, and automatic IP bans for brute-force login attempts.

Storage Management

Visual progress bars showing total capacity, used space, and free space on the FAT32 formatted SD card.

Role-Based Access Control (RBAC)

Users are securely managed in memory via C++ STL (`std::map`). Access is strictly controlled based on user level.

ADMIN

Full Control

  • Upload, Download, Delete files
  • Access System Info Page
  • Access Live Admin Console
  • Manage Banned IPs manually
USER

Standard Access

  • Upload files to SD
  • Download files from SD
  • Delete files from SD
  • View storage usage
VIEWER

Read-Only

  • View file list
  • Download files
  • Cannot upload
  • Cannot delete

Admin Console & System Info

Live Dashboard Updates

The web UI uses AJAX polling to fetch JSON data from /console/data, updating the dashboard in real-time without refreshing.

  • System Info: Chip model, Cores, CPU Freq, SDK version.
  • Memory: Heap info, Flash size & speed, Sketch size.
  • Network: AP IP, MAC address, Active connected clients.
  • Security: Live list of manually or automatically banned IPs.

Hardware & Software Setup

Required Libraries

Ensure these are installed in your Arduino IDE or PlatformIO:

  • WiFi.h & WebServer.h
  • SD.h & SPI.h
  • esp_wifi.h & esp_netif.h
  • Standard C++ STL (<map>, <list>, <set>)

SPI Wiring

Important: CS_PIN is specifically defined as GPIO 5 in the firmware.
